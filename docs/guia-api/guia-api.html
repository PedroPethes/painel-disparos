Guia da API

Puxar os dados via API

O painel de Disparos & Respostas expõe uma API de leitura. Você informa um período e recebe o log de eventos (cada disparo e cada resposta, com telefone) em JSON ou CSV. Cobre os bots de Welcome (Novos/Recorrentes) e de Carrinho Abandonado — como visões separadas.

Base & autenticação

URL base

https://SEU-DOMINIO.up.railway.app

Autenticação — envie o token no cabeçalho de toda requisição:

Authorization: Bearer SEU_TOKEN
O token é secreto e foi enviado a você separadamente. Não publique nem versione em repositório — quem tem o token vê os dados (inclusive telefones).

Endpoint — o log de eventos

GET/api/eventos

Aceita os parâmetros abaixo na query string:

ParâmetroValoresPadrãoO que faz
startDateAAAA-MM-DD30 dias atrásInício do período (fuso de Brasília).
endDateAAAA-MM-DDhojeFim do período (inclusivo).
segmentnovos · recorrentes · ambos · carrinhotodosFiltra a visão. ambos = só Welcome; carrinho = carrinho abandonado; vazio = todos.
etapadisparo · resposta · todastodasFiltra o tipo de evento.
formatjson · csvjsonFormato da resposta.
limit1–50001000Itens por página (só no JSON).
offset≥ 00Paginação (só no JSON).

Exemplos

1. Puxar os eventos de um período (JSON)

curl -H "Authorization: Bearer SEU_TOKEN" \
  "https://SEU-DOMINIO.up.railway.app/api/eventos?startDate=2026-07-01&endDate=2026-07-07"

2. Baixar um CSV (abre direto no Excel / Sheets)

curl -H "Authorization: Bearer SEU_TOKEN" \
  "https://SEU-DOMINIO.up.railway.app/api/eventos?startDate=2026-07-01&endDate=2026-07-07&format=csv" \
  -o eventos.csv

3. Filtrar (ex.: só as respostas dos recorrentes)

.../api/eventos?startDate=2026-07-01&endDate=2026-07-07&segment=recorrentes&etapa=resposta
Google Sheets: como o Sheets não manda cabeçalho, use o token na URL com &token=SEU_TOKEN e a fórmula =IMPORTDATA("…&format=csv&token=SEU_TOKEN"). Prático — mas lembre que quem vir a planilha vê o token.

O que volta

No JSON, cada item de events tem quatro campos:

{
  "period": { "startDate": "2026-07-01", "endDate": "2026-07-07" },
  "total": 1824,
  "events": [
    {
      "timestamp": "2026-07-06T09:02:11-03:00",
      "segmento":  "Welcome Novos",
      "etapa":     "disparo",
      "telefone":  "5531xxxxxxxxx"
    }
  ]
}

No CSV, as colunas são: timestamp,segmento,etapa,telefone.

  • timestamp — instante do evento, no fuso de Brasília (-03:00).
  • segmento — Welcome Novos, Welcome Recorrentes ou Carrinho Abandonado.
  • etapa — disparo (o bot iniciou a conversa) ou resposta (o cliente respondeu).
  • telefone — número do WhatsApp do contato (formato 55DDDNÚMERO) — a chave pra cruzar internamente.

Limites & regras

  • Período: padrão últimos 30 dias; máximo 180 dias por requisição.
  • Frequência: até 60 requisições/minuto e 500/dia por token.
  • Datas sempre no formato AAAA-MM-DD.
  • Sem token ou token inválido → 401. Período grande demais → 400.

Precisa só das contagens (funil por dia)? Use GET /api/funil com os mesmos startDate/endDate/segment.
